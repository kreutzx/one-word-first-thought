## The word

> Oops.

## Why this word

The brief asks for one word — the first thought. "Oops." is the most honest first thought there is: instant, unfiltered, and universally recognised as the sound of a mind reacting before it has time to compose itself. It needs no setup and no explanation.

## How it runs

`main.py` (Python, standard library only) writes the entry text plus a trailing newline to `/output/entry.txt`, creating `/output` if needed.
